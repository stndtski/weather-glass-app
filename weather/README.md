# Glass Weather App

A weather dashboard application featuring a modern Glassmorphism UI and dynamic background adaptation.

## Features
- **Real-time Weather Data:** Powered by Open-Meteo API.
- **Dynamic Backgrounds:** The interface adapts to current weather conditions (Sunny, Rainy, Snowy, etc.).
- **Glassmorphism Design:** Modern UI with blur effects and transparency.
- **Responsive:** Works on desktop and mobile.

## Technologies
- HTML5
- CSS3 (Variables, Flexbox, Animations)
- Vanilla JavaScript (Async/Await, Fetch API)

## How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
