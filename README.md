# 🌦️ Weather Glass Dashboard

A modern weather web application featuring a premium **Glassmorphism** design. This dashboard combines accurate meteorological data with beautiful visual effects and live animations to create an immersive user experience.


## ✨ Features

* **🎨 Liquid Glass Design:** The interface is built with a deep blur effect (backdrop-filter), vibrant colors, and volumetric shadows, creating a tactile and depth-filled aesthetic.
* **🌌 Live Animated Background:**
    * Smooth floating gradient orbs (Lava Lamp effect).
    * Realistic weather effects: rain, drifting clouds, and twinkling stars.
    * Automatic Day/Night cycle adaptation.
* **📊 Comprehensive Weather Station:** A unified Dashboard displaying over **20 weather metrics**:
    * **Health & Safety:** Air Quality Index (AQI) and UV Index with color-coded danger scales.
    * **Agro Data:** Soil temperature and moisture levels.
    * **Atmosphere:** Pressure, visibility, cloud cover, and dew point.
    * **Astronomy:** Moon phases, precise sunrise/sunset and moonrise/moonset times.
    * **Wind:** Speed, gusts, and direction (featuring an animated compass).
* **🛡️ Robust Stability (Safe Mode):** Smart API data handling. If specific data points (e.g., soil data or pollen) are unavailable for a selected location, the app gracefully handles missing values without errors (no NaN), ensuring a broken-free UI.
* **⚡ Optimized Performance:** The entire project is optimized and merged into a single file for instant loading and easy deployment.

## 🛠️ Tech Stack

* **HTML5 & CSS3:** Utilizes modern CSS variables, Grid Layout, and complex keyframe animations.
* **Vanilla JavaScript:** Clean, dependency-free code using ES6+ features and asynchronous data fetching.
* **Ionicons:** Vector icons used for crisp weather visualizations.

## 📡 API

This application is powered by open-source data from **Open-Meteo**:
* Geocoding API (City Search).
* Weather Forecast API (Meteorological Data).
* Air Quality API (AQI Data).

## 🚀 How to Run

No build process or dependencies required.

1.  Download the `index.html` file.
2.  Open it in any modern web browser.
3.  Enjoy the weather!
